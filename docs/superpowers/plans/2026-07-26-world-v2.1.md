**地图生成算法（冻结）：**

```typescript
// 16 个区域按固定配额分配类型：berry 8 / wood 4 / stone 2 / gold 2
// 分配方式：对 0..15 的区域索引做确定性洗牌，前 8 个给 berry，接着 4 个 wood，2 个 stone，2 个 gold
export function planRegions(seedRoot: string): RegionPlan[] {
  const idx = Array.from({ length: 16 }, (_, i) => i);
  // Fisher-Yates，键控随机
  for (let i = idx.length - 1; i > 0; i--) {
    const j = drawInt(seedRoot, i + 1, "region-shuffle", i);
    const t = idx[i]!; idx[i] = idx[j]!; idx[j] = t;
  }
  const quota: [ResourceKind, number][] = [["berry", 8], ["wood", 4], ["stone", 2], ["gold", 2]];
  const out: RegionPlan[] = [];
  let p = 0;
  for (const [kind, n] of quota) for (let k = 0; k < n; k++) out.push({ regionIndex: idx[p++]!, kind });
  return out.sort((a, b) => a.regionIndex - b.regionIndex);
}
```

每区站点数与站点参数（冻结）：

| kind | 每区站点数 | capacity | regrowPpmSummer | regrowPpmWinter |
|---|---|---|---|---|
| berry | 3 | 5 | 60_000 | 5_000 |
| wood | 2 | 8 | 8_000 | 2_000 |
| stone | 2 | 20 | 20_000 | 20_000 |
| gold | 1 | 3 | 500 | 500 |

```typescript
export function generateSites(seedRoot: string): Site[] {
  const sites: Site[] = [];
  const PER_REGION: Record<ResourceKind, number> = { berry: 3, wood: 2, stone: 2, gold: 1 };
  const PARAMS: Record<ResourceKind, { capacity: number; s: number; w: number }> = {
    berry: { capacity: 5, s: 60_000, w: 5_000 },
    wood: { capacity: 8, s: 8_000, w: 2_000 },
    stone: { capacity: 20, s: 20_000, w: 20_000 },
    gold: { capacity: 3, s: 500, w: 500 },
  };
  for (const { regionIndex, kind } of planRegions(seedRoot)) {
    const rx = (regionIndex % 4) * REGION_SIZE, ry = Math.floor(regionIndex / 4) * REGION_SIZE;
    for (let i = 0; i < PER_REGION[kind]; i++) {
      const p = PARAMS[kind];
      sites.push({
        id: `${kind}-${regionIndex}-${i}`,
        kind,
        pos: {
          x: rx + drawInt(seedRoot, REGION_SIZE, "site-x", regionIndex, i),
          y: ry + drawInt(seedRoot, REGION_SIZE, "site-y", regionIndex, i),
        },
        stock: p.capacity,
        capacity: p.capacity,
        regrowPpmSummer: p.s,
        regrowPpmWinter: p.w,
      });
    }
  }
  return sites;
}
```

**实现要点（逐条冻结）：**
- `createW2InitialState`：创始 NPC 位置 `drawInt(seedRoot, GRID, "spawn-x"/"spawn-y", npcId)`；`birthTick = -(adultAgeTicks + drawInt(seedRoot, max(1, elderAgeTicks-adultAgeTicks), "founder-age", npcId))`（沿用 v1 口径）；`carry` 四键全 0；`goal = null`；**`memory` 预置**：取距该 NPC 出生位置最近的 `manifest.founderSeededMemory` 个站点（按距离升序，平手按 site.id 的 UTF-16 序），`lastStock = site.stock`、`seenTick = 0`；`buildings = []`；`sites = structuredClone(manifest.sites)`。
- `environmentStep2`：每个站点按季节 ppm 再生 —— `if (site.stock < site.capacity && drawInt(seedRoot, 1_000_000, "regrow", site.id, state.tick) < ppm) site.stock += 1`；狼行为沿用 v1 语义——**注意：v1 的狼是随机游走**（`DIRS[drawInt(seedRoot, 8, "wolf", state.tick)]`），不是追击（本计划初稿此处写错，以 v1 代码为准，2026-07-27 更正）；相邻（Chebyshev ≤1）的存活 NPC 受 `wolfDamage`，写 `lastDamage = "wolf"` 并产出 `wolf_attack` 事件。
- `needsStep2`：能量 `-energyDrainPerTick`（下限 0）；能量为 0 时 `hp -= starvationHpDrain`，`lastDamage = "starvation"`，首次进入饥饿产出 `starving` 事件（沿用 v1 的去重口径：仅在"上一 tick 非饥饿、本 tick 饥饿"时产出）；**冬季且 `shelterAt(state, npc.pos) === null` 时 `hp -= winterColdHpDrain`，`lastDamage = "cold"`**；`npcAge2 > elderAgeTicks` 时 `hp -= senescenceHpDrain`，`lastDamage = "old_age"`；能量 ≥ `hpRegenEnergyMin` 时 `hp += hpRegenPerTick`（上限 `maxHp`）；`hp <= 0` 则 `alive=false`、`deathTick`、`deathCause = lastDamage ?? "unknown"`，产出 `death` 事件。
- `reproductionStep2`：沿用 v1 语义（可育条件、相邻配对、人口上限、`birthChancePpm`、双亲扣能量与冷却），子代 `carry` 全 0、`goal = null`、基因组来自 Task 6 的 `breed2`。**本任务先留一个注入点**：`reproductionStep2` 接受由调用方传入的 `breedFn`，Task 6 再接上真实实现——测试用桩函数。

- "记忆中最近的 X"：先筛 `kind === X && lastStock > 0`，按 `chebyshev2` 升序、平手按 `pos.x`/`pos.y` 升序取第一条。
