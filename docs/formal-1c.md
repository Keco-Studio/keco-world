## 2. 预注册预测的检验

预注册 §0.2 写下过一条对自己不利的预测，现在可以对账：

> "正式运行为 60k tick……按线性外推，12 个 seed 中约 **2 个会超过 800‰**；S3 结果处在恰好通过与失败的边界上。本方案预注册这个预测：S3 不是一道已经赢下的闸门。"

**实测：恰好 2 个 seed 越线**（c1-evolutionary-2 = 823‰、c1-evolutionary-7 = 876‰），10/12 通过，而阈值正是 `ceil(12×10/12)=10`——**以零余量通过**。终局 idle 分布：365 / 412 / 439 / 538 / 562 / 574 / 606 / 681 / 705 / 746 / **823** / **876**。

D2 的 60k 决定同样对账成功：预测 58–62 代，实测 **56–60 代**（50k 时为 47–52 代，S1 在 8/12 处失败）。

这两条对账的意义不是"我们猜得准"，而是：**S3 与 S1 都是真闸门，不是事后凑出来的通过条件**。若当初维持 50k，S1 会失败；若 S3 阈值再严 80‰，S3 会失败。

## 3. 归因分析：文化层的双面性（预注册 §3 末条要求）

### 3.1 修正试跑的因果判断（重要）

试跑记录 §2.4 曾断言"idle 爬升只出现在信念开启的臂"（依据是末两个 10k 窗口的边际斜率：Evolutionary +58‰/10k，NoCulture −14‰/10k）。**官方运行以更长程、更高功效的测量推翻了这个断言的强形式**：

| 臂 | 首 10 块均值 | 末 10 块均值 | Δ |
|---|---|---|---|
| Evolutionary（breed + 信念开） | 343‰ | 611‰ | **+268** |
| Evo-NoCulture（breed + 信念关） | 339‰ | 529‰ | **+190** |
| Handcrafted（clone + 信念关） | 367‰ | 377‰ | +10 |
| Fixed（clone + 信念关） | 280‰ | 297‰ | +17 |

**修正后的结论：idle 爬升的主因是繁殖/进化本身（两个 breed 臂 +190~+268，两个 clone 臂 +10~+17），文化层是放大器而非主因**（信念开启使爬升多约 78‰，即 +41%）。试跑那条判断错在测量窗口太窄（只看最后两个 10k 窗口）且样本噪声大——这正是形成性试跑不能当结论用的原因，也是预注册要求"正式运行专门检验"的价值所在。

### 3.2 文化层的正向作用：多样性维持

同一组对照给出了相反极性的另一半：

- **N2 多样性维持：Evolutionary 9/12 PASS，NoCulture 8/12 FAIL。** 关掉信念后，4 个 seed 的终局种群内行为多样性塌到创始值的 22%–58%（最低 0.0896 / 0.4066 = 22%）。
- N1（漂移）与 N3（远离基线）两臂都是 12/12 通过——**可遗传结构本身足以产生漂移与方向性新颖，但把种群内部的差异维持住的是文化层**。

### 3.3 合起来看

**文化层同时是"让世界更安静"和"让族群内部更不一样"的机制。** 前者是产品威胁（§15 观看无聊），后者是产品卖点（血脉之间可感的差异）。1C 的主终点——人类更想继续看哪条血脉——恰好是裁决这个张力的正确工具：如果观众在更安静但更多样的进化血脉与更活跃但同质的手工血脉之间选择前者，那么文化层的代价值得付。

这条张力应写入 Go/Iterate/Stop 的结论叙述，而不是当作脚注。

## 4. 观看无聊威胁的第三次量化

- 15k tick（退化检查）：idle 爬到 ~50% 平台，瞬时越线 3/6 种子。
- 50k tick（形成性试跑）：慢性化，最长连续 25,000 tick 超 600‰。
- **60k tick（本次官方）：终局均值 611‰，2/12 seed 越过 800‰ 静止线；连续越线块数最高 30 块（c1-evolutionary-3）。**

同一世界的 Handcrafted 臂 60k 全程稳定在 ~370‰。**这不是世界引擎的缺陷，是进化收敛的方向。**

**根因已定位**（docs/idle-convergence-diagnosis.md，2026-07-26）：世界食物长期匮乏（终局 97% 灌木为空），匮乏时效用层只剩 explore 与 idle 两个候选；而灌木位置固定、果子原地再生，使"守着等"严格占优于随机游走——进化因此把 explore 打到 idle 之下（候选分数 81→34 vs 50→119，跨 12 seed 一致：forage↑12/12、explore↓11/12），族群聚集在灌木周围（到最近灌木均距 2.86 vs 随机基线 4.92）。插桩确证末段 92% 的发呆动作直接来自 idle 键，且发呆时能量均值仅 570（不是吃饱没事干）。产品含义与处方选项见该诊断 §5–§6。
