### 0.2 诚实性披露：哪些参数是在试跑数据可见之后设定的

预注册的可信度取决于"阈值不是为了让结论好看而定的"。因此逐项披露：

**在看到试跑数据之后设定（D1 的阈值与计数口径、D2 的运行长度、D3 的判定基准）。** 形成性试跑的正当用途就是校准，但读者有权自行判断这些选择是否被结果牵着走。具体交代：

- **S3 阈值 800‰ 的先验理由**是"五分之四的行动是发呆＝世界已经静止"——这是一条我在任何数据之前都会给出的产品判断，且它是**静止下限**而非"好看"标准。但必须说明：我是在看到试跑末段分布（进化臂最高 800‰）之后落笔写下 800 这个数的，最差 seed 的余量只有 1‰。**不能声称"进化世界稳稳通过 S3"。**
- **明确的失败预测**：正式运行为 60k tick，比试跑长 20%，而 idle 在进化臂上单调爬升（末期中位数 +58‰/10k tick）。按线性外推，12 个 seed 中约 **2 个会超过 800‰**；按 D1 的"≥10/12 存活 seed 通过"计数，正式运行的 S3 结果处在**恰好通过与失败的边界上**。本方案预注册这个预测：S3 不是一道已经赢下的闸门。
- **未受试跑影响的参数**（早于试跑冻结）：主终点全部功效参数（§6.7，效应量 0.62 / n≥150 / 每人≤8 判断）、N 组三项阈值（源自 evo-1 单 seed 锚点，2026-07-22 记录）、传记采样预算与配对规则、S2/S4/S5。

### 0.3 试跑暴露的因果线索（正式运行须专门检验）

两个 breed 臂基因组机制完全相同，唯一差别是信念动力学开关，而 **idle 爬升只出现在信念开启的臂**（Evolutionary 末期 Δ 中位数 +58‰/10k，NoCulture −14‰/10k，Handcrafted +3‰/10k）。机制上讲得通：事件驱动形成的信念以 shelter/forage 增益为主，累积后把权重推向"待在庇护所"，而庇护所内的最优动作正是 idle。

含义：**项目最有辨识度的机制（文化层）可能同时是让世界变安静的机制。** 正式运行的归因分析（§3 末条）必须专门检验这条；若复现，"文化层提升叙事素材但降低可观看活动性"应作为主要发现之一写入结论，而不是脚注。

## 1. 实验臂与规模

| 臂 | 配置（makeArmSetup / cognition） | seeds | 用途 |
|---|---|---|---|
| Random | random / clone / off | 12 | sanity 下限（预期灭绝） |
| Fixed Utility | utility / clone / off，epsilon=0 | 12 | 无进化基线（与 Evolutionary 同创始分布） |
| Handcrafted | utility / clone / off，设计 epsilon 0–150 | 12 | 人工内容基线（25 原型 + 20 规则，工时已记录） |
| Evolutionary | utility / breed / on | 12 | **处理组（S 组判定基准）** |
| Evo-NoCulture | utility / breed / off | 12 | 信念清零对照（归因分析，不投闸门票） |

- 每 seed **60,000 tick**（D2），chunk=1000 分块链（哈希等价已测试钉死）。
- 世界：`makeDemoManifest()`，参数不动。
- 官方 seeds：`c1-<arm>-1` … `c1-<arm>-12`，arm ∈ {random, fixed, handcrafted, evolutionary, noculture}。形成性/试跑一律 `pilot-` 前缀，两个空间不相交。
- 预算：按试跑实测（50k × 60 seed = 35 分钟全管线）折算，60k × 60 seed ≈ 45 分钟运行 + 判据与素材约 5 分钟。

## 2. 生存稳定性硬闸门（S 组）

- **S1 存续**：≥10/12 seed 存活至 60k tick；Evolutionary/NoCulture 臂另需 maxGeneration ≥ 50（clone 臂免此项，代数语义不同）。
- **S2 无单一化塌缩**（仅 breed 臂）：终局基因组空间多样性 ≥ 创始值 30%，无偏 drawInt 配对采样；**全部存活 seed 均须通过**。
- **S3 世界未静止（终局判据，D1）**：每个**存活** seed 取运行**最后 10 个 chunk（10,000 tick）**的 idle 动作份额均值 `terminalIdle1000`；该 seed 通过当且仅当 `terminalIdle1000 < 800`。臂级通过当且仅当通过的存活 seed 数 ≥ `ceil(存活 seed 数 × 10/12)`。灭绝 seed 不计入分子也不计入分母（它们已由 S1 判定）；零存活 seed 时 S3 判失败。
  - **报告项（不设闸门，但必须进结论）**：全程 idle 轨迹、首 10 块与末 10 块均值及其差（观看无聊的量化）、连续越线块数（原窗口判据）。
- **S4 变异有界**：终局全部存活基因组过 zod 校验（全 seed 一致通过）。
- **S5 信念有界**：全程快照 max beliefs/NPC ≤ 16（全 seed 一致通过）。
- 报告不设闸门：epsilon 轨迹、血脉数轨迹、人口曲线、各基线臂存活率（D3：这些是对照数据）。

## 3. 行为新颖性硬闸门（N 组，Evolutionary 臂）

仪器：31 固定情境套件 + verbL1/n-gram。**epsilon 混淆应对**：跨臂原始多样性数字不可比（犹豫带压制多样性约 47%），故 N 组全部采用臂内自参照或方向性比较。

- **N1 行为漂移**：终局存活基因组池 vs 创始池池化比较，verbL1 ≥ **0.30** 的 seed 数 ≥ **9/12**。
- **N2 多样性维持**：终局池内两两行为多样性 ≥ 同 seed 创始值的 **60%** 且绝对值 ≥ **0.25** 的 seed 数 ≥ **9/12**（D6）。
- **N3 远离固定基线**：cross(evolved_evo, founders_fixed) ≥ cross(founders_evo, founders_fixed) 的 seed 数 ≥ **9/12**。
- **归因分析（不设闸门，但结论必须写）**：Evolutionary vs Evo-NoCulture 同 seed 对比，分解可遗传结构漂移与信念累积对 N1/N2 的贡献；**并专门检验 §0.3 的 idle 归因线索**。若 NoCulture 单独也能过 N1/N2，须如实声明"文化层对行为新颖性非必要"。

## 4. 主要终点：盲化成对偏好

- **任务**：一对等长盲化血脉传记（Evolutionary vs Handcrafted），唯一问题"更想继续看哪条血脉的后续？"，二选一强制。
- **功效参数（§6.7 冻结，未受试跑影响）**：H0 p=0.5 双侧 α=0.05；最小产品意义效应量 **0.62**；判断数下限 **150**、目标 **200**；每人 ≤8 判断且素材不重叠；聚类稳健标准误复核。
- **素材生成（机械规则）**：每臂每 seed 取存活血脉中代数最深 1 条 + `drawInt(seedRoot, n, "bio-pick", k)` 抽 2 条；跨代分层采样（4 段 × 3 事件，段内优先级 死亡>信念>出生，同级取更早 tick，余额顺延并回绕一次）；结语在评审包中为仅按存续状态的中性二态收尾（D10）；配对按代数带 1–15/16–30/31+ 匹配，渲染字符长度差 ≤20%（超出则带内重抽）；左右位置由 `drawInt(seedRoot, 2, "bio-side", pairId)` 定。
- **盲化核查表**：无 seed/tick/臂名/机制词；两臂共用 NAME_POOL；禁用词 grep 过检（算力/代币/模型/锦标赛/LoRA/世界进化 + 四个臂名 + 漂移短语 演变/并无显著改变/更热衷/更疏于）；**信念句对称性**：评审包统一为无时间戳的『信奉』单模板。
  - **残余风险如实声明**：信念句密度（进化臂跨成员多条 vs 手工臂仅始祖 ≤3 条）与措辞池多样性（内核 9 变体 vs 设计 21 条）仍是统计层面的潜在指纹。由形成性去盲探针专门测量；若探针显示评委能系统性识别，正式轮启动前必须先收紧（这构成 v3 触发条件之一）。
- **评委**：正式 ≥25 人；形成性 12–20 人先行（pilot 素材，不消耗官方素材池）。
- **形成性去盲探测（仅 pilot）**：问卷末尾追加开放题"你能猜出两条传记来自不同的生成系统吗？依据是什么？"。官方问卷不含此题。
- **通过判定**：双侧二项检验显著、方向为正、且点估计 ≥ 0.62。"显著但 < 0.62" → Iterate。

## 5. 次要终点（Holm–Bonferroni 家族校正，D8 三项全做）

1. 血脉特征回忆准确率（3 项单选）；
2. 三代因果复述完整度（自由文本，双评分员 0–3 锚定量表，Cohen's κ ≥ 0.6，否则裁决并修订 rubric）；
3. 关注转化率（是/否）。

评分细则：`docs/eval-rubric.md`。个体层指标（隔日回访、观看时长）本轮不采集（无产品化会话循环；按 DEC-4 它们本就不投票）。

## 6. 决策规则（Go / Iterate / Stop）

判定基准为 **Evolutionary 臂**（D3）。

- **Stop**：Evolutionary 臂 S1 失败（世界撑不住 50 代，前提不成立）**或** 主终点方向为负且 Wilson 上界 < 0.5（观众明确更爱手工内容）。→ 回 §15 威胁模型重审"进化是否产品必需"。
- **Go**：Evolutionary 臂 S1–S5 全过 **且** N 组全过 **且** 主终点通过。→ 进入 1B 产品化与阶段二准备。
- **Iterate**：其余全部情形（含 S2/S3 失败、N 组部分失败、主终点显著但 < 0.62）。→ 允许改指标/内容后发布 v3 并更换 seed 组。
- 基线臂（Random/Fixed/Handcrafted）的存活率与闸门结果**报告但不参与判定**（D3）。NoCulture 臂仅供归因。
- `npm run analyze` 打印的建议行按上述规则计算，**仅供参考，决策仍为人工**。

## 7. 运行纪律

- 首个官方 seed 启动前：本方案已冻结、分析代码 commit 已写入 §9、全部阈值不可变。**本条已满足。**
- 首次官方运行即记录。任何"重跑到通过"= 违规，发现即作废整组 seed。
- 官方运行目录含 `manifest.json`/`roster.json`/`meta.json`/`checkpoints.json`/`snapshots.jsonl`/`events.jsonl.gz`/`final-state.json.gz`/`directives.json`（恒为 `[]`）。
- **归档不含逐 tick 原始 action log**：内核确定性使其冗余（同 seedRoot + 同 manifest + 同 tick 数必然重放出逐字节相同的日志）。校验路径 = chain tip + 稀疏 checkpoint + 需要时对该 seed 做无插入严格重跑，比对 `finalStateHash`/`actionChainTip`；与 `npm run replay -- --strict` 同一验证哲学。
- 中途发现 runner bug：修复后整臂重跑（同 seed 允许——确定性内核下这是重放而非重采样），并在报告中记录修复。
