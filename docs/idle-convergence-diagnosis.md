# 为什么进化世界会变安静：根因诊断

**日期：** 2026-07-26 · **数据源：** 1C 官方归档（`runs/official/`，5 臂 × 12 seed × 60k tick）+ 对 `c1-evolutionary-7` 的插桩重演 · **方法：** superpowers:systematic-debugging（先根因、后处方）

**结论一句话：这个世界里"守在会重生的灌木旁等着"是真正的最优策略，进化找到了它。世界变安静不是缺陷，是最优化的结果——§15 预言的"生存最优但观看无聊"以一个可精确定位的机制实现了。**

---

## 1. 被证伪的三个假设（记录下来，因为它们看起来都很合理）

| 假设 | 证伪依据 |
|---|---|
| **H1 发呆省能量，因此被选择** | 代码里没有任何按动作计费的能量成本：`needsStep` 对所有存活个体无差别扣 `energyDrainPerTick`，移动不比发呆贵。直接收益不存在。 |
| **H2 有界无偏变异导致权重向中点漂移** | forage 冲到 926（离中点更远、贴天花板）、explore 掉到 129（离中点更远、贴地板）。方向明确，不是向心漂移。 |
| **H3 进化让族群吃饱，饱腹使效用函数失声** | 存活个体能量均值仅 **289/1000**，只有 **14‰** 处于 ≥850。插桩显示发呆决策时能量均值 **570**，能量 ≥900 的仅占 **3‰**。NPC 是饿着发呆的。 |

H3 值得单独说明：它在机制上完全成立（`forage`/`consume` 的分数都乘 `hungerNeed`，而 `idle` 分数是常数，所以吃饱确实会让生产性动作归零），但**实测数据说这条路径没被走到**——族群从来没富裕到那个程度。这是一个"机制存在但不是本案主因"的假设。

## 2. 根因链（逐环有实测支撑）

**环一：世界长期食物匮乏。** 官方终局 **97% 的灌木是空的**（144 个灌木里 139 空，全局仅剩 5 颗浆果），而每 seed 有 24–25 个存活个体。12 个灌木 × 容量 5 = 上限 60 颗，夏季再生 6%/tick、冬季 0.5%/tick——再生速度追不上消耗。**"看不见果子"是常态，不是例外。**

**环二：匮乏时效用层只剩两个候选。** 读 `scoreCandidates`（src/mind/utility.ts）：`consume` 需要库存浆果（存活个体库存均值 1）、`forage` 需要视野内有带果的灌木、`shelter` 只在冬季且不在庇护所时出现、`seekMate` 需要 reproReady 且旁边有可育成年。**这些条件都不满足时，候选只有 `explore`（分数 = w.explore × explorationBias / 1000）和 `idle`（分数 = w.idle 常数）。**

**环三：进化把 explore 打到 idle 之下，两者交叉。**

| | 创始 | 进化后（60 代） |
|---|---|---|
| w.explore | 200 | 129 |
| explorationBias | 404 | 260 |
| **explore 候选实际分数** | **≈ 81** | **≈ 34** |
| **idle 候选分数（= w.idle）** | **50** | **119** |
| 匮乏时谁赢 | **explore（游荡，世界看着活）** | **idle（站着不动，世界安静）** |

**环四：这是选择，不是漂移。** 12 个独立 seed 的一致性：**forage 上升 12/12**（+272…+379，全部贴到 875–962）、**explore 下降 11/12**、**idle 上升 10/12**。随机漂移不会产生这种一致方向。

**环五：插桩确证末端行为。** 重演 `c1-evolutionary-7`（终局 idle 876‰）的末 10k tick，25.6 万次决策：

```
发呆动作 224,560 次（876‰），其中
  idle 键产生      206,518  (920‰ of all idle)   ← 常数分数候选直接胜出
  seekMate 键产生   18,042  ( 80‰)               ← 相邻等待伴侣
非发呆的主要来源：forage:move 15,346 / shelter:move 5,676 / forage:take 3,819
```

**环六：为什么"守着等"是最优的。** 灌木位置**固定不动**、果子**原地再生**、视野半径 8（32×32 的地图上覆盖面很大）。因此随机方向游走（`explore` 的动作是 `drawInt` 抽的均匀方向，无记忆、无梯度）**没有信息收益**——没有新东西可发现——却有真实代价（离开已知灌木、暴露给狼、冬季远离庇护所）。守在灌木旁等再生严格占优。实测印证：**存活 NPC 到最近灌木的平均距离 2.86 格，而均匀随机基线是 4.92 格**——族群确实聚集在灌木周围。

配套的漂移方向也全都指向同一策略：`patience` 508→605（更能等）、`w.forage` 596→926（一见到果子就全力扑上去）、`w.shelter` 693→283（不为庇护所浪费时间）。

## 3. 文化层的位置（修正此前的判断）

试跑曾判断"idle 爬升由文化层驱动"，官方运行推翻了强形式：两个 breed 臂都爬（Evolutionary 首→末 +268‰，NoCulture +190‰），两个 clone 臂几乎不动（+10/+17‰）。**主因是繁殖/变异让策略可优化，文化层是放大器（约 +41%）。** clone 臂不爬正因为它们的基因组永不改变——策略停在创始水平，explore 仍然赢过 idle。

## 4. 还未验证的一环（诚实标注）

"探索被选择掉是因为它有真实代价（狼暴露、离开灌木）"这一步是**机制推断，未做隔离实验**。可证伪的检验：关掉狼的臂里 explore 权重是否仍然下降？或者测量个体 explore 权重与其繁殖成功数的关系。本诊断不需要它就能定位根因（环一至环五已经充分），但如果要动手改设计，这一步值得先做——它决定该拿掉代价还是该增加收益。

## 5. 处方选项（未实施，需产品决策）

根因是**世界的资源几何给不出移动的理由**，所以所有有效处方都指向"让搜索重新有价值"或"让静止有代价"：

1. **食物换位再生**：灌木采空后在别处重生 → 守着等失效，搜索有信息收益。最直接命中根因。
2. **削减视野 / 加入位置记忆衰减**：让"哪里有果子"重新成为需要维护的知识。
3. **给静止加代价**：狼优先攻击长时间不动的个体；或久坐降低体温/健康。
4. **增加与饥饿无关的动作动机**：建造、社交、照料后代等有独立收益的行为——这也是让世界"有事发生"的内容层答案。
5. **不改世界，改呈现**：接受"实时观看是安静的"，产品以传记/纪事为主体，实时视图作为点缀。

第 5 条值得单独重视：主终点测的恰恰是**读传记**的偏好，而不是实时观看。如果人评显示进化血脉的纪事更吸引人，那么本诊断的正确读法可能不是"世界坏了"，而是**"这个产品的载体应该是编年史，不是直播"**。

## 6. 时序建议

**先跑完 1C 人评，再动世界设计。** 理由：官方运行与素材包已归档，人评可以照常进行；而任何世界规则改动都会让官方运行失去可比性，新的正式主张需要预注册 v3 + 全新 seed 组。诊断结论应写入 1C 的结论叙述（它解释了 S3 为什么压线），而不是先改世界再回头解释数据。
